
   ## Section 2 - Study Techniques - ### My Contribution: Study Techniques for Week 00

As a Season 12 student (0383), effective study has been key to mastering Git. My top techniques are:
1.  **Active Recall:** Instead of just reading git commands, I close the tab and try to type `git status`, `git branch`, `git merge` from memory.
2.  **Teach to Learn:** I explain each step to myself or a teammate on WhatsApp - if I can teach `Branch -> PR -> Review -> Merge`, I truly understand it.
3.  **Pomodoro Technique:** 25 mins focused on one GitHub task (like Pages setup), then 5 mins break to avoid burnout.
   
These methods helped me complete my profile repo `Stephen-Dev254` and my live site https://Stephen-Dev254.github.io successfully.
