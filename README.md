## VS Code Tips - Shema Kevin
VS Code is my main code editor. My tips: Use Ctrl+P to quickly find any file, Ctrl+Shift+P for command palette, install extensions like Prettier for auto-formatting and Live Server. I use integrated terminal with Ctrl+` and use split screen to view 2 files at once.
